# exdpi-strategies

Облачные стратегии DPI-обхода для **EXDPI Pro**.

EXDPI Pro при запуске проверяет `manifest.json`: если поле `version` изменилось
относительно последней применённой, приложение скачивает перечисленные
`.bat`-стратегии в `%APPDATA%\EXDPI\strategies`, и они перекрывают встроенные.

## Как обновить стратегии клиентам

1. Положите/обновите файлы `general*.bat` в этом репозитории.
2. Добавьте их в список `strategies` в `manifest.json`.
3. **Увеличьте `version`** (например, `"1"` → `"2"`) — без этого клиенты не
   скачают обновление.
4. Готово: у всех активных Pro-пользователей стратегии обновятся при
   следующем запуске приложения.

## Правила

* В манифест попадают только файлы с именами `general*.bat` — остальное
  движок игнорирует.
* Версию (`version`) менять при каждом изменении набора файлов.
* Ссылки — raw-URL этого репозитория (ветка `main`).
